# LangGraph Human-in-the-loop: Custom Interrupt / Resume

## Описание

Реализация графа на LangGraph с кастомным прерыванием (interrupt/resume) для подтверждения действия пользователем через консольное меню. Граф останавливается на узле, запрашивает ответ через `questionary.select`, и после выбора возобновляет выполнение, сохраняя результат в состояние.

## Структура проекта

```
main.py      — основной файл с реализацией графа
README.md    — этот файл
```

## Зависимости

- Python 3.10+
- `langgraph` — граф с поддержкой прерываний и чекпоинтов
- `questionary` — интерактивный выбор в консоли

```bash

```

## Запуск

```bash

```

## Как это работает

1. **Состояние графа** — `TypedDict` с полями `human_value` (для ответа пользователя) и `foo` (для начальных данных).
2. **Узел `approval_node`** — вызывает `interrupt()` со словарём, содержащим тип прерывания, вопрос и варианты ответа. После возобновления извлекает ответ и сохраняет его в `human_value`.
3. **Сборка графа** — `StateGraph` с одним узлом, переходом из `START` в узел, компиляция с `InMemorySaver`.
4. **Цикл запуска** — `graph.stream()` обрабатывает чанки, при обнаружении `__interrupt__` извлекает payload, показывает вопрос через `questionary.select`, обновляет payload ответом и возобновляет граф через `Command(resume=...)`.
5. **Итог** — после завершения графа выводится финальное состояние с выбранным значением.

## Ожидаемый вывод

```
Произошла остановка
{'type': 'alert', 'question': 'Уверены что хотите продолжить?', 'allow_responds': ['approve', 'reject']}
!!! alert !!!
> Received an input from the interrupt: approve
{'node': {'human_value': 'approve'}}
Итоговое состояние: {'human_value': 'approve', 'foo': 'initial_data'}
```

## Критерии оценки

| Критерий | Статус |
|----------|--------|
| Состояние графа задано, узел возвращает обновлённое состояние после прерывания | ✅ |
| В узле вызывается `interrupt()` с объектом (вопрос + варианты ответа) | ✅ |
| Граф собран с чекпоинтером и успешно компилируется | ✅ |
| В цикле по чанкам обрабатывается `__interrupt__`, показывается вопрос и получается ответ пользователя | ✅ |
| Граф возобновляется через `Command(resume=...)`, выполнение доходит до конца и выводится итоговое состояние | ✅ |
